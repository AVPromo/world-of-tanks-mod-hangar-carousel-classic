# Installation

World of Tanks `2.4.0.1` or a compatible client is required. `net.openwg.gameface` is required for the carousel.

## Full package (recommended)

[Download the ZIP](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.19/hangar_carousel_classic_1.0.19_full.zip) and extract it into the WoT root directory. It includes HCC, ModsSettingsBridge, and GameFace for `mods/2.4.0.1/`. Aslain's Mod Menu is optional and is not bundled; obtain it separately via [Aslain's WoT ModPack](https://aslain.com/index.php?/topic/13-download-%E2%98%85-world-of-tanks-%E2%98%85-modpack/).

## HCC only

[Download the WOTMOD](https://github.com/ticzz/world-of-tanks-mod-hangar-carousel-classic/releases/download/v1.0.19/mod_hangar_carousel_classic_1.0.19.wotmod) and copy it to `mods/2.4.0.1/`. Also install the matching `net.openwg.gameface_*.wotmod` from the [OpenWG releases](https://gitlab.com/openwg/wot.gameface/-/releases).

Without Mod Menu and ModsSettingsBridge, HCC remains usable through the native carousel filter panel.
